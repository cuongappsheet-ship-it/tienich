Cấu hình API Google Sheet (GAS)

Nhập đường dẫn Web App Google Apps Script của bạn (URL có đuôi /exec). Khi bạn sửa giá trong Sheet, webapp sẽ tự động cập nhật ngay lập tức.

Hướng dẫn tạo API Apps Script cực nhanh:

  1. Trong Google Sheets chứa bảng giá của bạn, vào Tiện ích mở rộng (Extensions) > Apps Script.
  2. Dán đoạn mã doGet(e) được cung cấp trong hướng dẫn.
  3. Bấm Deploy (Triển khai) > New deployment > Chọn Web app.
  4. Mục Who has access (Ai có quyền truy cập) chọn Anyone (Bất kỳ ai) rồi copy URL dán vào đây.
